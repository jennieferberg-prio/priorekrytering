Vem ansvarar för dina personuppgifter?

{{ site.data.privacy.controller.name }} är personuppgiftsansvarig för den behandling som beskrivs i denna policy. Det betyder att vi bestämmer varför och hur personuppgifterna behandlas.

I ett rekryteringsuppdrag kan även det kundföretag som söker en medarbetare vara självständigt personuppgiftsansvarigt för sin behandling. Kundföretaget ansvarar då för att informera om sin hantering.

02

Vilka uppgifter behandlar vi och varför?

Ansökningar och rekryteringsprocesser

Vi behandlar till exempel namn, kontaktuppgifter, CV, personligt brev, svar i ansökningsformulär, arbetslivserfarenhet, utbildning, kompetenser, anteckningar från samtal och intervjuer, referenser samt övrig kommunikation.

Ändamål
Att ta emot och bedöma ansökningar, kommunicera med kandidater, genomföra urval och presentera relevanta kandidater i ett rekryteringsuppdrag.
Rättslig grund
Berättigat intresse av att genomföra en korrekt och effektiv rekrytering. Åtgärder som du själv begär inför ett möjligt anställningsavtal kan också stödjas på avtal. Om du vill finnas kvar för framtida möjligheter stödjer vi den fortsatta lagringen på ditt samtycke.

Spontanansökningar och kandidatnätverk

När du skickar en spontanansökan behandlar vi de kontakt- och merituppgifter samt filer du själv lämnar. Syftet är att kunna kontakta dig om framtida roller som kan passa din profil.

Rättslig grund
Samtycke. Du kan när som helst återkalla samtycket genom att kontakta oss. Återkallelsen påverkar inte behandling som redan skett innan den.

Search och headhunting

Vi kan behandla yrkesrelaterade uppgifter om potentiella kandidater, såsom namn, kontaktuppgifter, nuvarande och tidigare roller, arbetsgivare, utbildning, kompetens och information i offentliga yrkesprofiler. Uppgifterna kan komma från yrkesnätverk som LinkedIn, företags webbplatser, offentliga källor, rekommendationer eller våra uppdragsgivare.

Ändamål
Att identifiera och kontakta personer som kan vara relevanta för ett rekryteringsuppdrag.
Rättslig grund
Berättigat intresse. Vi väger behovet av rekrytering mot din rätt till privatliv och använder bara uppgifter som är relevanta i ett yrkesmässigt sammanhang. Du kan invända mot behandlingen.

Kund- och affärskontakter

När du kontaktar oss som kund, leverantör eller samarbetspartner behandlar vi exempelvis namn, roll, företag, kontaktuppgifter, meddelanden och uppgifter om vår affärsrelation.

Ändamål
Att besvara förfrågningar, lämna offerter, genomföra uppdrag och vårda affärsrelationer.
Rättslig grund
Avtal eller åtgärder inför avtal samt vårt berättigade intresse av att kommunicera med befintliga och möjliga affärskontakter.

Webbplats, drift och säkerhet

När du besöker webbplatsen kan tekniska uppgifter som IP-adress, webbläsare, enhet, tidpunkt och begärd sida behandlas i serverloggar. GitHub Pages, som levererar webbplatsen, loggar besökares IP-adresser för säkerhetsändamål. Behandlingen är nödvändig för vårt berättigade intresse av en säker och fungerande webbplats.

Lämna inte känsliga personuppgifter som uppgifter om hälsa, religion, politiska åsikter eller fackligt medlemskap i en ansökan om vi inte uttryckligen har bett om dem och informerat om hur de behandlas.

03

Vilka kan få del av uppgifterna?

Vi delar bara personuppgifter när det behövs för ändamålen ovan. Mottagare kan vara:

  • kundföretag i ett relevant rekryteringsuppdrag,
  • Ponty Technology AB, som levererar vårt rekryterings- och CRM-system,
  • Tally BV, som levererar formulär som används på webbplatsen,
  • GitHub, Inc., som levererar webbplatsen genom GitHub Pages,
  • Google Ireland Limited, om du har samtyckt till webbstatistik, samt
  • myndigheter eller rådgivare när det krävs enligt lag eller behövs för att fastställa, göra gällande eller försvara rättsliga anspråk.

Leverantörer som behandlar uppgifter för vår räkning får bara göra det enligt våra instruktioner och personuppgiftsbiträdesavtal. Ett kundföretag kan behandla uppgifter under eget ansvar när det bedömer kandidater för sin verksamhet.

Överföring utanför EU/EES

Vissa leverantörer kan behandla uppgifter i länder utanför EU/EES. När det sker ska överföringen stödjas på ett giltigt skydd, till exempel EU-kommissionens beslut om adekvat skyddsnivå eller standardavtalsklausuler, tillsammans med kompletterande skydd där det behövs.

04

Hur länge sparar vi uppgifterna?

Vi sparar aldrig personuppgifter längre än vad som behövs för ändamålet. Våra normala gallringsfrister är:

  • Aktuell rekrytering: under processen och upp till {{ site.data.privacy.retention.recruitment }}, bland annat för uppföljning och för att kunna hantera rättsliga anspråk.
  • Spontanansökan och kandidatnätverk: upp till {{ site.data.privacy.retention.candidate_network }}, eller kortare om du återkallar ditt samtycke.
  • Affärskontakter: normalt upp till {{ site.data.privacy.retention.business_contact }}. Uppgifter som ingår i bokföringsunderlag sparas så länge bokföringsreglerna kräver.
  • Tekniska loggar och statistik: enligt respektive leverantörs säkerhets- och gallringsrutiner samt tiderna i cookieöversikten nedan.

Uppgifter kan sparas längre om lag kräver det eller så länge de behövs för ett pågående rättsligt anspråk. Därefter raderas eller anonymiseras de.

06

Dina rättigheter

Beroende på omständigheterna har du rätt att:

  • få information om och en kopia av de personuppgifter vi behandlar om dig,
  • få felaktiga eller ofullständiga uppgifter rättade,
  • begära radering eller begränsning av behandlingen,
  • invända mot behandling som grundas på berättigat intresse,
  • återkalla ett samtycke, och
  • i vissa fall få ut uppgifter i ett maskinläsbart format.

Rättigheterna gäller inte utan undantag. Vi kan till exempel behöva behålla vissa uppgifter för att uppfylla en rättslig skyldighet eller försvara ett rättsligt anspråk. Vi kan be dig styrka din identitet innan vi lämnar ut eller ändrar uppgifter.

Vi använder inte personuppgifter för beslut som enbart grundas på automatiserad behandling och som har rättsliga eller motsvarande betydande följder för dig.

Om du inte är nöjd med vår hantering kan du lämna klagomål till Integritetsskyddsmyndigheten (IMY).
