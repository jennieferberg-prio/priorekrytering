# SEO - att göra

Bra SEO handlar främst om att Google ska förstå företaget, kunna läsa sajten utan problem och hitta innehåll som svarar på sådant potentiella kunder faktiskt söker efter.

## 1. Teknisk grund

- [ ] Lägg till canonical-adress på varje sida
- [ ] Skapa `robots.txt`
- [ ] Skapa `sitemap.xml`
- [ ] Lägg till Open Graph-data för snygga länkar på bland annat LinkedIn
- [ ] Skapa en särskild social preview-bild
- [ ] Lägg till strukturerad data för `Organization` och `WebSite`
- [ ] Lägg till favicon och relevanta app-ikoner
- [ ] Kontrollera att varje sida har en unik titel och metabeskrivning
- [ ] Ge bilder relevanta alt-texter
- [ ] Komprimera bilder och ange bilddimensioner för bättre laddningstid
- [ ] Kontrollera mobilprestanda och Core Web Vitals

Förslag på sidtitlar:

- Startsida: `Rekryteringsföretag för search och headhunting | Prio Rekrytering`
- Om Prio: `Om Prio Rekrytering | Personlig search i hela Sverige`
- Lediga jobb: `Lediga jobb | Prio Rekrytering`
- Kontakt: `Kontakta Prio Rekrytering`

## 2. Google Search Console

- [ ] Säkerställ att domänen är verifierad
- [ ] Skicka in `https://priorekrytering.se/sitemap.xml`
- [ ] Begär indexering av startsidan, Om Prio, Kontakt och Lediga jobb
- [ ] Kontrollera indexeringsproblem och varningar
- [ ] Följ vilka sökfraser som ger visningar och klick

## 3. Innehåll som kan ranka

Skapa ett fåtal genomarbetade undersidor i stället för många tunna och nästan identiska sidor.

- [ ] Headhunting och search
- [ ] Rekrytering inom bygg och närliggande branscher
- [ ] Rekrytering i hela Sverige
- [ ] Så går rekryteringsprocessen till
- [ ] Verkliga kundcase och omdömen när de finns
- [ ] Beskriv Jenniefers erfarenhet och expertis tydligare

Använd naturligt relevanta uttryck som `rekryteringsföretag`, `headhunting`, `search`, `hela Sverige` och `byggbranschen`. Undvik keyword stuffing och massproducerade ortssidor med nästan samma text.

## 4. Lediga jobb

- [ ] Låt varje riktig tjänst få en egen sida och permanent URL
- [ ] Gör jobben redigerbara via Pages CMS
- [ ] Lägg till `JobPosting`-data på varje aktiv jobbannons
- [ ] Ta bort eller avpublicera strukturerad jobbdata när tjänsten inte längre är öppen

`JobPosting` ska inte användas på den tomma samlingssidan eller för spontanansökan.

## 5. Förtroende utanför sajten

- [ ] Skapa eller färdigställ Google Business Profile om verksamheten är berättigad
- [ ] Färdigställ LinkedIn-företagssidan och länka den från webbplatsen
- [ ] Samla in genuina kundomdömen
- [ ] Försök få relevanta länkar från kunder, partner och branschorganisationer
- [ ] Använd samma företagsnamn och kontaktuppgifter i alla kanaler

## 6. Mätning

- [ ] Börja med Google Search Console
- [ ] Bestäm senare om vanlig webbanalys behövs
- [ ] Ta hänsyn till samtycke och integritet om Google Analytics eller marknadsföringsverktyg införs

## Rekommenderad ordning

1. Implementera det tekniska SEO-paketet.
2. Koppla och konfigurera Google Search Console.
3. Skapa de viktigaste tjänstesidorna.
4. Bygg stöd för individuella jobbannonser när riktiga annonser ska publiceras.
5. Arbeta löpande med case, omdömen och relevanta externa länkar.
